## Núcleo: Atlas Cognitive Kernel (ACK)

Toda entrada a Atlas pasa por 8 fases invariantes:

```
INPUT → [0: Clasificación] → [1: Hechos] → [2: Evidencia] → 
[3: Hipótesis Primaria] → [4: Alternativas] → [5: Refutación] → 
[6: Confianza] → [7: Impacto] → [8: Memoria] → OUTPUT
```

**Garantía:** Cada conclusión es trazable, auditable, y tiene audit trail.
