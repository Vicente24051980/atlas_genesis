# BRIDGE DESTRUCTION REGISTER Ω

**Status:** CANONICAL REGISTER — DINASTÍA HISTÓRICA Ω v2  
**Date:** 2026-09-06

## Frozen survival rule
A bridge survives only if at least one argument connects the endpoints without ultimately depending on Toumanoff or on a bibliographic chain that returns to the same reconstruction. Repetition in handbooks or derivative scholarship is not independent corroboration.

## Allowed outcomes
- `SURVIVES` — independent argument sufficient for the frozen claim.
- `PARTIAL` — independent support exists for part of the bridge, but not for the full frozen claim.
- `DOCUMENTARY GAP` — surviving evidence is insufficient; this does not mean false.
- `CONTRADICTED` — positive evidence is incompatible with the frozen claim.
- `DEPENDENCY LOOP` — apparent corroboration ultimately returns to the same evidentiary root/reconstruction.
- `CLOSED-UNRESOLVED` — Stop Rule met; do not reopen for another derivative repetition.
- `CLOSED-PARTIAL` — broad claim survives only in a narrower form.
- `CLOSED-SURVIVES` — frozen claim survives, while stronger unstated claims remain prohibited.

## Stop Rule Ω
Close only after relevant known primary evidence, materially independent secondary arguments where available, dependency roots, surviving/failing layers and pending evidence classes have been audited. Reopen only for materially new evidence or a genuinely independent new argument.

## Narrative Capture rule
`claims_descent_from ≠ descends_from` applies to the aggregated macromap. Prestigious ancestry assigned by an interested source is first evidence of dynastic memory/legitimation.
