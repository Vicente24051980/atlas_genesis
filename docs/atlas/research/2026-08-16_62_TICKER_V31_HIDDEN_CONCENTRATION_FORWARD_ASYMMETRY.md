## Escalas

- Forward Asymmetry: A alta; B favorable; C equilibrada/menos atractiva; O optionality especulativa.
- ADVANCE no implica compra automática. RESERVE_DUE_CONCENTRATION significa que el negocio puede ser excelente pero añadirlo junto a equivalentes aumenta concentración oculta.

## Hidden concentration — bloques causales

### AI compute / semis / connectivity — concentración máxima
TSM, NVDA, ASML, AMD, SNPS, MTSI, CRDO, LITE, FN, SK hynix, NVTS, STM.

No deben tratarse como doce apuestas independientes. El factor común es AI CAPEX → compute → memory → lithography → connectivity/optics → power semis.

### AI power / data-center physical stack
PWR, SU.PA, GEV, FIX, VRT, NXT, VST, RWE, CAT.

PWR/SU.PA/GEV/NXT ofrecen mejor diversificación industrial dentro del bloque; FIX/VRT tienen exposición más directa al ritmo de data-center CAPEX.

### AI platform / software
GOOGL, MSFT, AMZN, META, NOW, SNOW, IOT, RBRK, RDDT, FTNT.

Aquí el riesgo común no es sólo demanda AI sino CAPEX payback y monetización. Se mantiene separado del hardware aunque ambos dependan del mismo régimen de inversión.

### Aerospace / defense
GE, SAF.PA, HWM, RR.L, EXENS.PA.

Factor común: ciclo aeronáutico/defensa; diversificación interna razonable por motores, componentes, power systems y optrónica.

### Healthcare
LLY, MEDP, COR, WST, ABT, HALO, ALNY, ARGX.

Concentración oculta baja/moderada; drivers clínicos, distribución y tooling distintos.

### Financial rails / platforms / insurance
V, MA, ICE, IBKR, WISE, ADYEN, NU, CB, PLMR.

Diversificación interna aceptable. V/MA comparten el mismo rail; ICE/IBKR/WISE/ADYEN/NU tienen modelos y drivers diferentes.

## Hallazgo principal

La cartera/universo parece diversificado por ticker, pero el mayor riesgo oculto es la suma de dos cadenas conectadas:
1. AI compute/connectivity.
2. AI power/data-center physical infrastructure.

Juntas pueden reaccionar a la misma variable: desaceleración de AI CAPEX o deterioro del payback de hyperscalers. Por ello un grupo con NVDA + TSM + ASML + CRDO + LITE + FN + MTSI + VRT + FIX + GEV + PWR no equivale a once riesgos independientes.

## Reglas del siguiente paso
1. Winner Preservation: no vender un ganador probado únicamente por haber subido.
2. Para H3 exigir mayor Forward Asymmetry que para H0/H1.
3. Dentro de cada cadena H3, elegir los mejores economics/valuation y mantener los demás como reservas.
4. Optionality (NVTS/MP) no puede desplazar automáticamente a compounders probados; debe tener tamaño y falsificadores propios.
5. FN queda ADVANCE_COND_EVENT: Economic Proof Gate aprobado con datos Q3; revisar Q4/FY26 del 17-ago-2026.
6. No modificar cartera por esta auditoría; primero completar valoración/IV y comparación marginal entre sustitutos.
