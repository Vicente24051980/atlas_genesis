This module integrates the useful structures from the current research thread without creating a parallel architecture, score, portfolio gate, or autonomous state machine.

## Invariants

1. **Economic value created != value captured != FCF captured.**
2. **Agent capability != agent economics.**
3. Sponsored/conversational agents are evidence candidates for agentic commerce; they are not proof of profitable monetization.
4. Personal-agent competition and agent-to-agent coordination are tracked as category observations until retention, paid demand, transaction frequency, unit economics and defensibility are demonstrated.
5. AI infrastructure evidence is decomposed into **COMPUTE -> INTERCONNECT -> NETWORKING -> MEMORY -> SOFTWARE**. A catalyst in one layer cannot be automatically propagated to the others.
6. Memory supply tightness requires independent fundamental corroboration. Price action cannot prove a supercycle.
7. **Clinical evidence != commercial evidence.** Health follows: Discovery -> Preclinical -> I -> II -> III -> Approval -> Reimbursement -> Addressable patients -> Adoption -> Revenue -> Operating leverage -> FCF.
8. Private valuation headlines are observations. Mechanical valuation scenarios are not fair-value conclusions.
9. Every proposed promotion remains behind **HUMAN_REVIEW_REQUIRED** and existing Falsifiers Ω veto.
10. No module here can trade, modify portfolio state, or write canonical state.
