## 1. External Intelligence Layer Ω

Fuentes externas —sell-side, hedge-fund positioning, AInvest/AIME, vídeos, podcasts, newsletters, screeners, opciones y social— son **discovery**, nunca decisión final.

Cadena obligatoria:

**External Signal → Source Verification → Fundamental Validation → Economic Proof → Valuation Reset → Expected Return → Competition for Capital**.

Ley:

**EXTERNAL SIGNAL ≠ EVIDENCE ≠ BUY**.

Vídeos/podcasts/newsletters se clasifican L4 salvo que la afirmación quede reconciliada con L1/L2.

## 2. Momentum Discovery Ω

Momentum sólo fabrica candidatos.

**Abnormal Return + Abnormal Volume → Candidate Discovery → Fundamental Validation → Valuation Reset → Expected Return T1 → Compare ER T1 vs ER T0 → Competition for Capital**.

Reglas:
- RSI no determina Expected Return 3–6Y.
- Momentum no eleva Business Quality.
- Price ↑ sin mejora equivalente de fundamentals puede reducir Expected Return.
- Si **Fundamentals ↑ pero Price ↑↑ y ER ↓**, clasificar **WEAKENING**, no strengthening.

Ley:

**MOMENTUM ≠ FUNDAMENTAL VALIDATION ≠ BUY**.

## 3. Theme Decomposition Ω

Un retorno temático agregado es sólo una señal de discovery.

**Theme Return → Open Components → Theme Breadth → Remove Existing Holdings → Fundamental Audit → Economic Proof → Valuation Reset → Expected CAGR 3–6Y → Challenger Score → Competition for Capital**.

Medir breadth para distinguir liderazgo amplio de concentración en pocos componentes.

Leyes:

**THEME RETURN ≠ COMPONENT FUNDAMENTALS**  
**THEME RETURN ≠ CAPITAL FLOW**  
**THEME MEMBERSHIP ≠ BUY**.

## 4. AI Demand Financing Quality Ω

Separar calidad de financiación de la demanda AI:

- **A — Self-funded:** CAPEX financiado por FCF/balance del comprador.
- **B — Third-party financed:** project finance, PE, infrastructure funds, private credit.
- **C — Vendor-supported:** proveedor invierte, garantiza, financia o absorbe riesgo contingente para facilitar deployment.

Cadena:

**Funding Source → Financing Terms → Capacity → Deployment → Customer Acceptance → Revenue → Gross Profit → OCF → FCF/share → ROIC**.

Aplicar descuento de calidad creciente cuando la demanda migra A → B → C, salvo evidencia de economics superiores que compensen el riesgo.

Preguntas obligatorias:
1. ¿Quién paga realmente el CAPEX?
2. ¿Qué parte es self-funded vs project/vendor-supported?
3. ¿Qué riesgo contingente asume el proveedor?
4. ¿El FCF incremental compensa ese riesgo?

Ley:

**CUSTOMER DEMAND ≠ CUSTOMER ABILITY TO SELF-FUND DEMAND**.

## 5. NVDA Price/Margin Pass-Through Ω — refuerzo

Descomponer:

**HBM/BoM Cost ↑ → Server ASP ↑ → Capture**.

Tres estados:
- **ABSORPTION:** coste ↑; NVDA absorbe; margen presionado.
- **PASS-THROUGH 1:1:** precio ↑ ≈ coste ↑; revenue nominal ↑; economics aproximadamente neutrales.
- **PASS-THROUGH > COST:** precio ↑ > coste ↑; pricing power; gross profit/FCF potencialmente ↑.

Nunca inferir mejora económica de NVDA sólo por incremento del precio final del servidor.

## 6. Refining Normalization Ω

Para VLO, MPC, PSX, DINO y futuros refiners, prohibido capitalizar beneficios de crack-spread excepcional como perpetuidad.

Cadena:

**Current Crack Spread → Normalized 3–5Y Crack Spread → Utilization → Operating Cost/bbl → Normalized EBITDA → Maintenance CAPEX → OCF → FCF/share → Buybacks/Dividends → Normalized Expected CAGR**.

Evaluar además:
- crude slate y feedstock advantage;
- regional product balances;
- turnaround/maintenance cycle;
- RIN/LCFS/regulatory costs;
- balance/debt;
- refining vs midstream/chemicals diversification;
- net share-count reduction;
- terminal multiple sobre economics normalizados.

Ley:

**LOW P/E AT PEAK EARNINGS ≠ CHEAP**.

## 7. Hard Assets / Gold — owner-economics bridge

No inferir miner BUY desde gold price.

**Gold Price → Realized Price → AISC → Margin/oz → OCF → FCF/share → Balance → Capital Return**.

Para leveraged ETFs de mineras, no usar como holding compounder 3–6Y sin mandato táctico independiente.

Ley:

**GOLD ↑ ≠ MINER FCF/share ↑**.

## 8. Technical/Engineering Proof Gate Ω

En tecnología industrial/EV/robotics:

**Engineering Proof → Manufacturing Scalability → Unit Economics → Margin → FCF/share → ROIC**.

Una innovación técnica no produce BUY si no cruza manufacturing economics y owner economics.

Ley:

**ENGINEERING ADVANTAGE ≠ MANUFACTURING ADVANTAGE ≠ COST ADVANTAGE ≠ FCF/share**.

## 9. Source Reconciliation Gate Ω

Antes de usar un dato de screener/FinQuery/agregador para expulsar un incumbent:

1. reconciliar periodo;
2. reconciliar definición contable;
3. reconciliar moneda/share class;
4. verificar con L1/L2 cuando sea material;
5. separar TTM de forward y MRQ de FY;
6. usar métricas sectoriales correctas.

Ejemplos de veto metodológico:
- no aplicar ROIC industrial a bancos;
- no comparar FCF bancario con FCF industrial;
- no usar P/E TTM deprimido para vetar una inflexión sin forward economics;
- no inventar explicación para anomalías de datos.

Ley:

**DATA ANOMALY → SOURCE CHECK, NO NARRATIVE PATCH**.

## 10. Competition for Capital — implementación

Todo challenger debe pasar dos combates:

**Expected CAGR 3–6Y Challenger**  
→ **vs weakest relevant incumbent**  
→ **vs weakest absolute incumbent**  
→ **KEEP / REPLACE / WATCH / REJECT**.

No existe slot gratuito por sector, diversificación o exposición única.

Ley:

**UNIQUE EXPOSURE ≠ FREE PORTFOLIO SLOT**.
