# MCR-2026-08-28-AI-VALUE-MIGRATION-RECEIVERS

**Status:** ACCEPTED / CANONICAL  
**Effective:** 2026-08-28  
**Parent canon:** ATLAS Ω v4.0 / AI Value Distribution Ω

## Change

Se registra **AI VALUE MIGRATION / RECEIVER GATE Ω** como submódulo transversal de AI Value Distribution Ω para detectar receptores económicos del profit pool de IA más allá de compute.

## Motivation

La evidencia de 2026 muestra una divergencia creciente entre:

- crecimiento extraordinario de infraestructura/compute;
- presión de CAPEX y financiación en hyperscalers/AI infrastructure;
- monetización emergente en enterprise workflows, systems of record, trusted data y aplicaciones agentic.

ATLAS necesitaba separar formalmente:

`SOURCE-LAYER FUNDAMENTALS`

from

`TARGET-LAYER ECONOMIC CAPTURE`

from

`EQUITY PRICE RESPONSE`.

## Canonical rules added

1. Una caída en NVDA/MRVL o una subida en software **no demuestra** migración causal de capital.
2. Un receptor requiere `T2+` para ser `RECEIVER_CANDIDATE`; T4 para `ECONOMIC_RECEIVER_CONFIRMED`; T5 para `DURABLE_VALUE_RECEIVER`.
3. La confirmación de migración es de cohorte y exige evidencia económica independiente y persistencia; no se obtiene de un ticker ni de una sesión.
4. System of Record, Workflow Control, Trusted Data y Distribution Control se registran como posibles puntos de captura.
5. Capex-heavy receivers siguen sometidos a Capital Malinvestment, Cash Reality, CFQ y Financed Demand.
6. El módulo no tiene autoridad BUY/SELL, no modifica cartera ni evade Valuation, Competition for Capital, Falsifier Veto o Decision Safety Gate.
