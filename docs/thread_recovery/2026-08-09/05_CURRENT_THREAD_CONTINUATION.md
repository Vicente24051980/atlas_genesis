## Falsifiability Gate Ω

For conspiratorial or extraordinary claims, ATLAS asks:

`What evidence would count as sufficient to show this hypothesis is false?`

If no conceivable evidence can count against the claim because all counter-evidence is reinterpreted as further proof of concealment, the model has stopped investigating and begun protecting a belief.

The inverse error must also be avoided: an extraordinary claim is not false merely because it is extraordinary. The evidentiary standard simply rises with the claim.
