# ATLAS Ω — GitHub + Notion Sync Law

Status: CANONICAL / INVIOLABLE
Effective: 2026-08-12

## Rule
Every relevant ATLAS Ω analysis, rule, engine, portfolio decision, score framework, canonical conclusion, watchlist change, source-policy change, falsifier, implementation decision, or material information that is promoted from chat into ATLAS must be persisted in BOTH:

1. GitHub — technical/versioned source of truth.
2. Notion — operational/documentation mirror.

A chat-only implementation is incomplete.

## Scope
This applies to Finance, Portfolio, Watchlist, GREEN CONTINUITY Ω, QUALITY Ω, IMPLIED RETURN Ω, ENTRY TIMING Ω, MARKET BOTTOM Ω, MONEY ROTATION Ω, AI CAPEX PAYBACK Ω, source/evidence policy, Atlas Genesis/App, health/project branches when the information is being incorporated into ATLAS, and future ATLAS branches/modules.

## Persistence protocol
- GitHub stores canonical/versioned technical or normative state.
- Notion mirrors the operational/documentary state.
- Material changes must be synchronized in the same work session whenever connector access permits.
- If one destination cannot be updated, explicitly report the failure; never claim synchronization occurred.
- Superseded canon must be updated or marked superseded rather than silently contradicted.

## Governance
This rule may only be changed by an explicit later instruction from Vicente.
