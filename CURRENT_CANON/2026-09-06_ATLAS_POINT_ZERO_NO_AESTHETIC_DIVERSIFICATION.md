# ATLAS Ω — NO AESTHETIC DIVERSIFICATION

Portfolio construction cannot award independent utility merely for having more sectors, countries, capitalization buckets, narratives or factor labels.

If the best return/risk opportunities cluster, concentration is permitted.

Diversification has value only to the extent that modeled portfolio risks genuinely offset or common fragilities decline; it is not a target in itself.

`DIVERSIFICATION_AS_APPEARANCE = ZERO_AUTHORITY`
