## Canon decision
ATLAS incorporates **CAPITAL STYLE ROUTER Ω v1.0** as a mandatory routing layer for candidates discovered through CAPITAL INTELLIGENCE Ω or any allocator/family-office/holding-company signal.

This registration resolves a scoring contamination found during the 2026-09-04 Exor/Lingotto/Wallenberg audit: a high-quality operating compounder, an earnings-normalization case, a listed allocator/holding and a strategic turnaround must not be judged by the same primary scoring engine.

## Mandatory route
`CAPITAL INTELLIGENCE DISCOVERY -> CAPITAL STYLE ROUTER Ω -> STYLE-SPECIFIC ANALYSIS -> COMMON ATLAS GATES -> COMPETITION FOR CAPITAL -> PORTFOLIO DECISION`

## Primary classes
- `QCO` — QUALITY COMPOUNDER Ω
- `NCO` — NORMALIZATION / CONTRARIAN Ω
- `ALO` — ALLOCATOR INTELLIGENCE Ω
- `STO` — STRATEGIC TURNAROUND Ω

Exactly one primary class is required before a style-specific thesis score is produced.

## Score separation — mandatory
Never blend these as if they measured the same thing:
- `CAPITAL_SIGNAL_SCORE`
- `THESIS_SCORE`
- `FINAL_COMPETITION_SCORE`

A strong allocator signal is a discovery advantage, not company-quality evidence and never a BUY override.

## Governance constraints
1. Existing ATLAS Evidence, Valuation, GREEN, Expectations, Entry, Risk, Competition for Capital, portfolio concentration and Replacement Firewall gates remain authoritative.
2. CAPITAL INTELLIGENCE Ω remains a SENSOR; this addendum does not create autonomous BUY/SELL authority.
3. Style class migration requires date-stamped evidence and an explicit falsifier update.
4. `NCO -> QCO` requires confirmed normalization and durable reinvestment economics.
5. `STO -> QCO` requires FCF confirmation and durable repaired economics.
