# ATLAS Ω — PORTFOLIO STATE SEMANTICS

Use distinct terms:

- `CURRENT_OPERATIONAL_PORTFOLIO`: what is currently implemented/confirmed.
- `CLEAN_SELECTED_PORTFOLIO`: output of a valid Point Zero rebuild.
- `TRANSITION_TARGET`: clean selection translated through downstream implementation constraints.
- `HISTORICAL_PORTFOLIO`: prior snapshot retained for provenance.
- `CHALLENGER`: eligible non-selected competitor at the cut frontier.

Never use `CURRENT`, `CANONICAL`, `OPTIMAL` and `TARGET` interchangeably.
