# ATLAS Ω — DUPLICATE INVARIANCE TEST

Given an economic entity E represented once versus repeated multiple times in raw universe input, after canonical deduplication:

- E's company-level score must be identical;
- E's confidence must be identical absent new independent evidence;
- E must receive exactly one portfolio competition entry;
- selected portfolio membership must not improve merely from repetition.

This test operationalizes the 650→487 dedup law.
