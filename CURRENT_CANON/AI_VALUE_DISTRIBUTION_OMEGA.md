`COMPUTE -> CUSTOM_SILICON -> CLOUD -> MODELS -> INFERENCE -> ORCHESTRATION -> DATA -> APPLICATIONS -> SYSTEM_OF_RECORD -> DEVICE/OS DISTRIBUTION -> END USER ECONOMIC OUTPUT`

`CAPABILITY -> ADOPTION -> USAGE -> CUSTOMER ACCEPTANCE -> REVENUE -> MARGIN -> FCF -> INCREMENTAL ROIC`

`CAPEX + DEPRECIATION + SBC/DILUTION + SUPERVISION + SECURITY + FINANCING + CUSTOMER INCENTIVES`
