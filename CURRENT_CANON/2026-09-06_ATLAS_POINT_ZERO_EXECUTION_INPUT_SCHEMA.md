# ATLAS Ω — POST-SELECTION EXECUTION INPUT SCHEMA

Only after clean selection may execution consume:

`CURRENT_OPERATIONAL_PORTFOLIO`
`BROKER_AVAILABILITY`
`POSITION_SIZING`
`TAX_COST`
`TURNOVER_COST`
`LIQUIDITY`
`ENTRY_TIMING`
`ORDER_STAGING`
`IMPLEMENTATION_HYSTERESIS`

These fields can alter timing or implementation sequence but cannot modify `CLEAN_SELECTED_PORTFOLIO`, `CLEAN_RANKING` or `OPTIMAL_N`.
