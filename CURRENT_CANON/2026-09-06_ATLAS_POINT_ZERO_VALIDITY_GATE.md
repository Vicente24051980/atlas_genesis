# ATLAS Ω — POINT ZERO REBUILD VALIDITY GATE

A reported portfolio is not a canonical ATLAS rebuild unless all conditions below are satisfied:

- correct versioned universe is declared;
- deduplication to canonical entities is demonstrated;
- Point Zero is explicit;
- broad screening precedes shortlist;
- current holdings receive zero selection advantage;
- no fixed N or aesthetic quota binds selection;
- fundamentals, valuation, Expected Return, risk and falsifiers are evaluated;
- comparable and cross-sector capital competition are performed;
- OPTIMAL_N is derived from portfolio-set marginal utility;
- cut frontier is shown;
- anti-bias audit is shown;
- `DATA_CUTOFF` and confidence are reported;
- missing material data are labeled `UNKNOWN`.

If any condition is absent, label the output `PARTIAL_RESEARCH`, `SHADOW_RUN` or `NON_CANONICAL_EXPERIMENT`, not a canonical selected portfolio.
