# ATLAS Ω — FUTURE IPO GATE Ω

**Status:** CANONICAL_COMPATIBLE / ACTIVE  
**Effective date:** 2026-08-17  
**Purpose:** prevent narrative/private-valuation bias in Future 2027 and subsequent private-to-public candidates.

## 1. Core law

**IPO EVENT ≠ BUY SIGNAL.**  
**PRIVATE VALUATION ≠ PUBLIC FAIR VALUE.**  
**RUN-RATE REVENUE ≠ AUDITED REVENUE.**  
**STRATEGIC FUNDING ≠ INDEPENDENT END DEMAND.**

## 2. Lifecycle states

- `F0_PRIVATE_DISCOVERY`
- `F1_CONFIDENTIAL_FILING_REPORTED`
- `F2_PUBLIC_S1_AVAILABLE`
- `F3_PRICED`
- `F4_LISTED_PRICE_DISCOVERY`
- `F5_LOCKUP_SUPPLY_DISCOVERY`
- `F6_NORMALIZED_PUBLIC_COMPANY`

No candidate can receive a full Principal Ω verdict before `F2_PUBLIC_S1_AVAILABLE` unless equivalent audited public financials exist.

## 3. Mandatory pre-entry gate

`Audited financials → revenue quality → gross margin → operating income → OCF → FCF/share → CAPEX/compute commitments → CFQ → Financed Demand → debt/leases/recourse → dilution → governance/minority rights → related-party transactions → customer concentration → reverse valuation → offering structure → lock-up/supply → Entry Timing Ω`.

## 4. IPO supply / reflexivity

Record:

- primary vs secondary shares
- total shares outstanding / float
- greenshoe
- employee/investor lockups
- staged unlocks
- founder/super-voting control
- expected index/passive eligibility
- strategic-holder concentration
- insider liquidity needs

A low float can create an artificial post-IPO price spike; this is not fundamental evidence.

## 5. States

- `IPO_READY_PASS`: audited economics, funding and governance pass; valuation still separate.
- `IPO_READY_CONDITIONAL`: business passes but valuation/governance/funding needs a gate.
- `IPO_DATA_INCOMPLETE`: confidential/private data insufficient.
- `IPO_EXPECTATION_DENSE`: public price requires unusually aggressive growth/payback assumptions.
- `IPO_SUPPLY_DISTORTED`: float/lockup dynamics dominate price discovery.
- `IPO_NO_PASS`: material economic/governance/funding defect.

## 6. Decision safety

No automatic buy on first day, index inclusion, famous sponsor, scarcity, oversubscription or first-day rally.

**Entry requires public evidence + valuation asymmetry + acceptable supply structure.**
