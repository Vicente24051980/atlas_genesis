# ATLAS Ω — PROMPT WORLD MIGRATION PRINCIPLE

Old prompts are not physically deleted when they contain useful provenance. Their selection authority is removed.

Migration states:

- `SOLE_CANONICAL_SELECTION_AUTHORITY` — only the current Master Universe Prompt.
- `SUBORDINATE_ENGINE_OR_EVIDENCE` — still operational inside scoped role.
- `EXECUTION_ONLY` — post-selection implementation logic.
- `HISTORICAL_SUPERSEDED` — retained for provenance, no current authority.
- `SHADOW_EXPERIMENT` — research only until ratified.

This status model prevents two simultaneous canonical portfolio worlds.
