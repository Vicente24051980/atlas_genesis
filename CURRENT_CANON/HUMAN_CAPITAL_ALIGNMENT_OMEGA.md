# HUMAN CAPITAL ALIGNMENT Ω v1.0

Date: 2026-08-20
Status: ACTIVE / CANONICAL

## Purpose
Measure whether compensation architecture converts employees into durable economic co-owners without creating unacceptable dilution, labor conflict, retention risk or asymmetric downside transfer.

## Pipeline
Compensation event → cash/equity mix → vesting/lock-up → dilution source → employee alignment → retention/critical-talent effect → labor response → per-share economics → capital allocation interaction → falsifiers → decision.

## Required outputs
- Human Capital Alignment Ω: POSITIVE / NEUTRAL / NEGATIVE
- Retention Signal
- Labor Risk
- Dilution Risk
- Per-share Value Impact
- Evidence status: FACT / HYPOTHESIS / INTERPRETATION / NOISE

## Hard rules
1. Equity compensation is not automatically positive.
2. Alignment must be evaluated net of dilution and labor friction.
3. Treasury shares, newly issued shares and repurchased/cancelled shares must be distinguished.
4. A favorable compensation event cannot create BUY by itself.
5. Feed the result into Economic Proof Ω, FCF Conversion Ω, Shareholder Return Ω and Falsifiers Ω without double counting.
