# ATLAS Ω — IMPLEMENTATION OVER DOCUMENTATION CHECK

A clean-looking master prompt is insufficient if active code still enforces an obsolete rule.

Therefore every constitutional change must be checked at four levels:

1. authority document;
2. current-canon registry/pointers;
3. runtime implementation;
4. tests/CI expectations.

A legacy rule found only in historical provenance is harmless if clearly superseded. The same rule found in active runtime or canonical tests is an open defect.
