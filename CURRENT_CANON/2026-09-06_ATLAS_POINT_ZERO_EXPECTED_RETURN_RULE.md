# ATLAS Ω — EXPECTED RETURN RULE

Expected Return is forward-looking from the current evidence/price cutoff, not from the user's personal cost basis.

It should bridge fundamental growth, margins/FCF economics, capital returns, valuation/multiple normalization and material dilution/financing effects under a 3–6 year horizon.

Personal gain/loss is irrelevant to clean selection.

`EXPECTED_RETURN_FROM_TODAY ≠ RETURN_SINCE_PURCHASE`
