# AI Token Economics + Bidirectional Broadening Ω

Status: ACTIVE CANON
Effective: 2026-08-21

## Objective
Detect AI equity monetization without forcing a sequential C1→C2→… propagation model. Separate falling inference unit costs from economic value capture and detect simultaneous strengthening at physical-infrastructure and hyperscaler layers.

## 1. AI Token Economics Ω

Never interpret $/token in isolation.

Primary economic variable:

`AI_VALUE_EFFICIENCY = economic_value_generated / inference_cost`

Required decomposition when evidence exists:
- input token price
- output token price
- model tier: frontier / mid-tier / open-weight
- inference volume/utilization
- revenue or measurable economic value generated
- gross-margin / FCF consequence

Guardrails:
- token_price_down != monetization_down
- token_price_up != pricing_power unless quality/performance mix is controlled
- cheaper inference can be bullish when utilization/value grows faster than unit cost falls
- benchmark or third-party token pricing is a leading/context indicator, never Economic Proof by itself

## 2. Bidirectional Broadening Ω

Canonical state machine:
- NONE: no verified strengthening at either extreme
- PHYSICAL_ONLY: C1/C2 strengthen, hyperscalers do not
- HYPERSCALER_ONLY: C16 strengthens, physical layers do not
- TWO_EXTREMES: C1/C2 and C16 strengthen simultaneously, C3 not confirmed
- CONFIRMED_BIDIRECTIONAL: C1/C2 and C16 persist while C3 breadth/RS confirms
- BROAD_CHAIN: confirmation extends beyond C3 into intermediate layers

Sequential propagation is NOT required. The market may reprice both extremes before intermediate layers.

## 3. Confirmation gates

All market-dependent inputs MUST pass Universal Market Tape Integrity Ω.

C16 cannot be promoted by one green session or two green megacaps alone. Require verified persistence plus breadth/relative-strength evidence.

C3 is the arbitration layer for the current regime:
- C1/C2 strong + C16 strong + C3 weak => TWO_EXTREMES only
- C1/C2 strong + C16 strong + C3 breadth/RS improving persistently => CONFIRMED_BIDIRECTIONAL

Opening noise is not confirmation. Use the post-opening gate before promotion.

## 4. Apple / product-reallocation rule

Headcount cuts or product-team restructuring are corporate evidence, not capital-flow evidence.

AAPL or any single constituent price move cannot establish C19 distribution. Require breadth + persistence + verified market tape.
