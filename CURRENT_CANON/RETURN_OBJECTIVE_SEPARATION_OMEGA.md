## Purpose
Prevent ATLAS Ω from confusing historical return, expected return, business quality or composite opportunity.

## Constitutional separation
1. HISTORICAL RETURN — verified past-window market return.
2. EXPECTED RETURN — evidence-backed forward CAGR from verified P0.
3. BUSINESS QUALITY — moat, economics, durability and capital efficiency.
4. COMPOSITE OPPORTUNITY — integrated multi-engine opportunity view.

BEST COMPANY ≠ HIGHEST EXPECTED RETURN.

## Pure-return law
Requests for retorno/rentabilidad/Expected Return/CAGR route to EXPECTED RETURN unless explicitly anchored to a historical period.

## GREEN-FIRST ANALYTICAL SEQUENCING Ω — 2026-08-22
GREEN CONTINUITY Ω is the first analytical engine after source/evidence integrity, ticker/listing identity normalization and synchronized market-tape validation.

Canonical sequence:

`EVIDENCE/IDENTITY INTEGRITY → GREEN CONTINUITY Ω → ALL APPLICABLE ATLAS ENGINES → EXPECTED RETURN BEAR/BASE/BULL → DURABILITY → VALUATION → RISK/FALSIFIERS → FINAL RANK`

Rules:
- GREEN 5/5 and 4/5 are strong continuity states, not final recommendations.
- GREEN 3/5 remains opportunity-eligible with caution.
- GREEN 0–2/5 never terminates research; the full audit continues and the weak state remains visible.
- GREEN is price-continuity evidence only. It is not Economic Proof, capital flow, intrinsic value or a BUY signal.
- Dislocation of price ≠ undervaluation ≠ entry signal.
- Every candidate in a declared competition must be audited; ATLAS may not silently exclude names because they are disliked, cyclical, expensive or initially weak.
- Final objective: maximize evidence-backed expected return per unit of risk among candidates surviving integrity, Economic Proof and falsifier gates.

## EXPECTED RETURN calculation
`P̄_h = Σ(probability_i × P_terminal_i)`

`Expected CAGR = (P̄_h / P0)^(1/h) - 1`

Standard 3Y probabilities when explicitly selected:
`P̄_3 = 0.20 × P_bear + 0.60 × P_base + 0.20 × P_bull`

Scenario CAGRs are never averaged directly.

## PRICE & TARGET INTEGRITY GATE Ω
Before canonical Expected Return ranking, P0 requires exact ticker/listing, currency/quotation unit, observation date, observation type, timestamp if intraday, source/evidence identifier and corporate-action normalization.

Bear/Base/Bull targets must be reconstructed on the same per-share scale/currency using contemporaneous fundamentals, dilution/share-count assumptions, balance sheet and explicit terminal valuation method.

### Fail-closed invariant
`MATH PASS ≠ DATA PASS`

`P0 FAIL → P0 DELETE + P3 DELETE + CAGR DELETE + RANK DELETE`

Never repair contaminated P0 while preserving inherited P3 targets.

Regeneration chain:
`VERIFIED P0 → CONTEMPORARY FUNDAMENTALS → BEAR/BASE/BULL P3 → EXPECTED TERMINAL VALUE → CAGR → FALSIFIER GATE → RANK`

Missing, stale, contradictory or unreconciled required data produces:
`EXPECTED RETURN → EVIDENCE_PENDING / INVALIDATED`

No placeholder target, guessed scale or inherited target may fill the gap.

## Economic Proof survival gate
Economic Proof is a survival gate, not a return bonus. Falsifiers Ω remains an absolute veto. Quality, GREEN, momentum and Money Rotation may be displayed as independent diagnostics but may not silently add points to a pure EXPECTED RETURN ranking.

## Required ranking labels
Every ranked output must explicitly identify its objective: HISTORICAL RETURN, EXPECTED RETURN, BUSINESS QUALITY or COMPOSITE OPPORTUNITY. Expected Return must expose P0 date/type and verification state.
