# ATLAS Ω — REBUILD REPRODUCIBILITY METADATA

A canonical rebuild should record enough metadata to reproduce or audit the decision state:

- universe version;
- data cutoff;
- entity deduplication result;
- scoring/engine versions where material;
- missing/UNKNOWN variables;
- shortlist/finalist provenance;
- portfolio utility policy/version;
- OPTIMAL_N and frontier;
- selected portfolio/challengers;
- anti-bias audit outcome.

Without these, later portfolio differences can be misattributed to methodology when they actually came from changed data or universe state.
