# ATLAS Ω — Investment Committee Ω

**Status:** ACTIVE · Canonical
**Effective:** 2026-08-17
**Transversal-engine correction:** 2026-08-19

## Purpose
Convert ATLAS from prompt-driven analysis into an evidence-driven decision system. Agents do not vote; evidence and vetoes decide.

## Canonical pipeline

`OBJECTIVE → CONTEXT → SPECIALISTS → EVIDENCE → ADVERSARIAL DEBATE → CONTRADICTIONS → DECISION → EXECUTION → MEASUREMENT → LEARNING`

For investments:

`TICKER → ALL REGISTERED ATLAS ENGINES → EVIDENCE PACKET → CONTRADICTIONS → EXPECTED RETURN 3–6Y → FALSIFIERS Ω → INVESTMENT COMMITTEE Ω → ACTION`

Economic chain where relevant:

`REAL-WORLD SIGNAL → VALUE CHAIN → LISTED BENEFICIARIES → DEMAND → CAPTURE → CONVERSION → FCF → ROIC → MOAT → VALUATION → EXPECTED RETURN 3–6Y → FALSIFIERS Ω → ACTION`

## Universal ticker / all-engine sweep

Every ticker submitted to ATLAS must be processed by **all registered engines** before the final recommendation is issued.

There is no preclassification that allows ATLAS to route a ticker only through “defensive”, “growth”, “AI”, “value” or another preferred path. Engines remain independent and may return a positive state, negative state, `NO_SIGNAL`, `NOT_APPLICABLE`, `INSUFFICIENT_DATA` or an equivalent explicit result.

No engine is permitted to silently disappear from the ticker ledger when the registry requires it.

The sweep includes, where registered in the active canon:

- Economic Proof Ω;
- Quality / Financial Quality / Growth Ω;
- Valuation / Implied Return Ω;
- CAPEX Productivity Ω;
- Moat Ω;
- GREEN CONTINUITY Ω;
- Money Rotation Ω / Institutional Rotation Ω;
- Defensive Ω;
- Macro / Regime Ω;
- Recovery / Successor / Good Companies Cheap / Historical Dislocation and other specialized engines;
- GURUS & FUNDS Ω;
- Falsifiers Ω / Red Team;
- Evidence Director Ω.

The purpose is not to average every score. It is to preserve independent evidence and expose contradictions before decision.

## Committee — independent agents

1. **Economic Proof Ω** — validates Demand → Capture → Conversion → FCF → ROIC. No narrative substitute.
2. **Valuation / Implied Return Ω** — estimates forward 3–6Y return independently of business quality.
3. **CAPEX Productivity Ω** — audits incremental economic output per incremental capital deployed and payback.
4. **Moat Ω** — tests durability, switching costs, network effects, IP, scale, distribution and erosion.
5. **Institutional Rotation Ω** — measures abnormal flows, positioning, breadth and sponsorship; flow is a signal, never fundamental proof.
6. **Macro / Regime Ω** — evaluates rates, liquidity, credit, FX, commodities and regime sensitivity without overriding company evidence.
7. **Falsifiers Ω / Red Team** — adversarially attempts to invalidate the thesis. Independent absolute veto.
8. **Evidence Director Ω** — source hierarchy, provenance, contradictions, missing evidence and confidence.

Additional transversal engines retain their own local state and are ingested into this committee rather than promoted directly into portfolio actions.

## Defensive Ω — transversal, not a default bias

Defensive Ω must run on **every ticker** and return the ticker's degree of defensiveness / regime resilience.

Its output is a characteristic, not a default veto and not an automatic preference. A ticker may be an excellent BUY with a low Defensive Ω score, or highly defensive with an unattractive Expected Return.

Defensive Ω receives greater decision weight only when the explicit mandate is defensive portfolio construction or when the current objective specifically requests that dimension.

## GREEN CONTINUITY Ω — transversal, not final authority

GREEN CONTINUITY Ω must run on every ticker with sufficient history.

- `GREEN 5/5` is positive price-continuity evidence.
- A 1W or 1M break while 3M / 1Y / TOTAL remain positive is a continuity warning.
- A 3M, 1Y or TOTAL break is a structural price-trend warning.

None of those states is by itself a final BUY, HOLD, WATCH, SELL or REJECT instruction. Final recommendation belongs to Investment Committee Ω.

## Non-negotiable governance

### No majority voting
A 7–1 bullish committee does not produce BUY. Evidence gates determine state.

### No single-engine recommendation authority
No individual engine — including GREEN, Defensive, Money Rotation, Quality, Recovery, CAPEX or GURUS — may convert its local output directly into the final portfolio recommendation.

The sole exception in governance is **Falsifiers Ω**, whose confirmed material veto remains absolute and independent.

### Falsifiers Ω = absolute independent veto
Any confirmed material falsifier can invalidate E-Proof, valuation and expected return:
- technological disruption;
- fraud / governance failure;
- material regulation;
- financial deterioration;
- destructive capital allocation;
- structural moat loss.

An E5 company can therefore be REJECTED.

### E-Proof and valuation are orthogonal
Operational excellence does not imply an attractive security price. A company can be E5 and WATCH/REJECT because valuation compresses expected 3–6Y return.

### Regime is context, not identity
Macro / Regime Ω can raise or lower execution risk, discount rates, sizing and probability distributions. It must not redefine the ticker as inherently defensive, growth or otherwise, nor override company evidence without a valid gate.

### Epistemic ledger
Every material assertion is tagged as **FACT / HYPOTHESIS / INTERPRETATION / NOISE** and must carry source, date, freshness and confidence where available.

Causal statements such as “the decline was technical / regime-driven” are `INTERPRETATION` unless independently demonstrated.

### Null opportunity is valid
The system must be able to conclude **NO OPPORTUNITY / NO PORTFOLIO CHANGE**. It is prohibited from manufacturing a recommendation to satisfy the search process.

## Decision gates

- **BUY:** thesis valid + sufficient Economic Proof + moat acceptable + expected return clears hurdle + no active veto + execution gate permits entry.
- **HOLD:** thesis valid but incremental purchase does not clear hurdle or sizing constraints.
- **WATCH:** evidence incomplete, valuation insufficient, catalyst not validated, setup not mature, or material engine contradictions remain unresolved.
- **REJECT:** confirmed falsifier, structurally inadequate economics, or expected return decisively inadequate.
- **NO OPPORTUNITY:** evidence does not justify portfolio action.

## Engine ledger requirement

For every analyzed ticker, persist at minimum:

- ticker / canonical identifier;
- as-of timestamp and market cut;
- each engine name/version;
- local engine state / score;
- source provenance and freshness;
- FACT / HYPOTHESIS / INTERPRETATION / NOISE tags;
- contradictions between engines;
- Falsifiers state;
- final Investment Committee recommendation;
- execution state separately from fundamental recommendation.

A `BUY` plus `NO_CHASE` is valid: BUY is the fundamental committee recommendation; NO_CHASE is an execution instruction, not a downgrade of the thesis.

## Evidence Director Ω protocol

For every deep research run:
1. define falsifiable question;
2. prioritize primary sources;
3. separate facts/hypotheses/interpretations/noise;
4. collect evidence for and against;
5. expose contradictions explicitly;
6. list missing data and NO VERIFICADO tests;
7. score source quality/freshness/confidence;
8. pass the same evidence packet to every registered engine;
9. record explicit NO_SIGNAL / NOT_APPLICABLE / INSUFFICIENT_DATA outputs where relevant;
10. run Red Team after the positive case, not before;
11. issue action only after all hard gates.

## Continuous learning loop

After each decision, preserve the contemporaneous evidence packet and forecast. At checkpoints compare predicted vs realized Demand, Capture, FCF, ROIC, margins, valuation and catalysts. Update calibration; never rewrite historical evidence retroactively.
