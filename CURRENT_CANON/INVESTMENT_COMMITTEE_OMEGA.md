## Why this file changed

The historical Investment Committee architecture was useful in moving ATLAS from prompt-driven analysis toward evidence-driven analysis, but it accumulated responsibilities that are now represented more cleanly by the ratified E1–E6 architecture.

The full pre-consolidation text remains recoverable in Git history. This current path intentionally prevents an old `ACTIVE · Canonical` declaration from competing with the current canon.

## Current mapping

Historical committee functions are hosted by the six canonical engines:

- evidence packets, source hierarchy, identity, PIT and epistemic tags → `E1 EVIDENCE Ω`
- Economic Proof, Quality, Growth, Valuation, Expected Return, moat, CAPEX and specialized analytical outputs → `E2 ASSESSMENT Ω`
- Falsifiers, hard vetoes and binding preconditions → `E3 GATE Ω`
- portfolio utility, selection and action proposal → `E4 DECISION Ω`
- permissions, human approval, persistence, scheduling, revocation and shutdown → `E5 CONTROL Ω`
- evaluation harness, backtests, calibration and negative controls → `E6 ASSURANCE Ω`

## Current decision pipeline

`R0 RESEARCH → E1 EVIDENCE → E2 ASSESSMENT → E3 GATE → E4 DECISION → EXECUTION`

- E5 is transversal control and does not generate the investment conclusion.
- E6 is independent assurance and does not approve execution.
