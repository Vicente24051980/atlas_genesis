## Core chain
`Physical Demand → Institutional Accumulation → Equity Monetization → Layer Transition`

## Dual Institutional Accumulation
A name receives `DUAL INSTITUTIONAL ACCUMULATION` when independently evidenced data show both hedge funds and active mutual funds adding exposure over the same disclosed measurement period.

Required fields:
- issuer/ticker identity integrity
- source and report vintage
- measurement period and disclosure lag
- hedge-fund direction
- mutual-fund direction
- magnitude when available
- AI layer / GICS mapping
- current price/breadth/RS state
- Economic Proof state
- Expected Return state
- falsifiers

## Temporal integrity
Quarterly positioning is historical evidence.

Hard laws:
`13F / QUARTERLY ACCUMULATION ≠ CURRENT FLOW`
`INSTITUTIONAL POPULARITY ≠ ECONOMIC PROOF`
`INSTITUTIONAL POPULARITY ≠ BUY`
`DUAL CONSENSUS ≠ POSITIVE EXPECTED RETURN`

Current-flow claims require current evidence. Never silently carry Q2 positioning into Q3 as if purchases are continuing.

## Integration with AI Layer Flow Confirmation Ω
Institutional positioning is a slow prior. Current layer state remains determined by verified market evidence including price, breadth, relative strength, persistence and cross-layer confirmation.

Possible states:
- `INSTITUTIONAL PROOF + EQUITY MOMENTUM` — stronger confirmation
- `INSTITUTIONAL PROOF + NO CURRENT MOMENTUM` — latent/watch state
- `CURRENT MOMENTUM + NO INSTITUTIONAL PROOF` — price-led state
- `DUAL ACCUMULATION + NEGATIVE EXPECTED RETURN` — NO BUY / valuation block

A C4–C6 layer cannot be promoted merely because institutions accumulated constituents during the previous quarter.
