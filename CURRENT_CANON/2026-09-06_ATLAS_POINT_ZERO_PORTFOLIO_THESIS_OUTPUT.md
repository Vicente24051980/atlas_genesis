# ATLAS Ω — SELECTED POSITION THESIS OUTPUT

For each selected name, final output should answer compactly:

1. Why this company?
2. Why now at this valuation?
3. What 3–6 year return bridge is expected?
4. What is the main permanent-loss/fragility risk?
5. What evidence would falsify the thesis?
6. Which named competitor/challenger is most likely to take its slot?
7. What key variable remains UNKNOWN?

This forces portfolio membership to remain contestable over time.
