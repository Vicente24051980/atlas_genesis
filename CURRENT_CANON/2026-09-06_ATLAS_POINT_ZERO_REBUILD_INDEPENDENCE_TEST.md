# ATLAS Ω — INDEPENDENT REBUILD TEST

A rebuild is independent only if the selector could plausibly return a radically different portfolio without violating its instructions.

Red flags indicating non-independence:

- current portfolio supplied as seed set;
- shortlist restricted mainly to incumbents/challengers from the old cut;
- replacement analysis used instead of full-universe screening;
- prior rankings retained as priors;
- current N retained as default target;
- conclusions framed as justification of current holdings.

Passing test: the process begins from the versioned canonical universe and evaluates current holdings on exactly the same basis as non-holdings.
