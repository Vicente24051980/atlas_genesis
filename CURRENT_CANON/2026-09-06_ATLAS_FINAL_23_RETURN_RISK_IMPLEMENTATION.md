## Decision law

A security receives capital only if its current composite score is >=85/100 under the frozen decision frame:

- Expected return 3–6y: 30%
- Quality / moat / capital efficiency: 20%
- ARRM / fundamental acceleration: 15%
- Growth + revisions: 15%
- Valuation / expectations: 10%
- Volatility + drawdown + balance-sheet risk: 10%

A challenger enters only when it improves the portfolio return/risk frontier. Same-sector concentration is permitted. No sector minimums or maximums exist for aesthetic reasons.

4. A one-quarter acceleration cannot by itself create promotion.
5. No 13F, guru, manager or narrative signal can authorize a trade.
6. Any score change must cite new evidence, not price action alone.
