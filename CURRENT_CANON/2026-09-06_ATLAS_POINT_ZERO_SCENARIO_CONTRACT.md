# ATLAS Ω — BULL / BASE / BEAR SENSITIVITY CONTRACT

Every canonical final portfolio must be stress-tested conceptually across bull, base and bear scenarios using the same evidence cutoff.

The sensitivity output should distinguish:

- names that survive all three scenarios;
- names whose membership depends on base/bull assumptions;
- names whose Expected Return remains high but permanent-loss/fragility risk becomes unacceptable in bear;
- names whose valuation only works under aggressive terminal assumptions;
- names whose fundamental thesis is robust but entry price/Expected Return is scenario-sensitive.

Scenario sensitivity is diagnostic and may alter return/risk utility; it cannot be used to impose sector or factor quotas.
