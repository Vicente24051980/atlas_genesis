# ATLAS Ω — RETRIEVAL AUTHORITY TAGS

Recommended metadata/status tags for documents:

`PHASE1_SELECTION_ALLOWED`
`PHASE1_EVIDENCE_ONLY`
`PHASE1_ENGINE_DEFINITION`
`PHASE2_EXECUTION_ONLY`
`HISTORICAL_PROVENANCE_ONLY`
`SHADOW_NONCANONICAL`

The goal is to let retrieval respect authority boundaries mechanically, not merely through prompt prose.
