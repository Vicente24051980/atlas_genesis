# ATLAS Ω — BROAD-SCREEN AUDIT METRICS

A broad-screen artifact should report at least:

- number of canonical entities received;
- number screened;
- hard-gate failures;
- data-incomplete/UNKNOWN cases;
- number promoted to shortlist;
- external challengers added and provenance;
- entity identity exceptions;
- evidence cutoff/freshness distribution where relevant.

This prevents “full universe” from becoming an unverifiable claim.
