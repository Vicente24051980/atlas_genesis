# ATLAS Ω — CURRENT 27 HAS NO DEFENSE BURDEN

In a clean rebuild, a current holding does not need to be “disproved” before exclusion, and a challenger does not need to overcome an incumbent-specific burden of proof.

Both start from zero and must earn their place positively under the same evidence standard.

The burden is symmetric: **earn the slot**.

This prevents the current 27 from becoming a de facto protected portfolio merely because every exit is framed as a replacement prosecution.
