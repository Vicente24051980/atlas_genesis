# ATLAS Ω — POINT ZERO REPOSITORY AUDIT QUESTIONS

For every potentially active selector/registry/test, ask:

1. Does it load current holdings before clean selection?
2. Does it contain a fixed min/max position count?
3. Does it prefer incumbents in ties or impose incumbent-specific hurdles?
4. Does it reward diversification independently of modeled economic risk?
5. Does it reward market cap, fame, index membership or data availability?
6. Can it admit/exclude directly from a subordinate engine output?
7. Does it bypass valuation, Expected Return or falsifier veto?
8. Does it expose N→N+1 marginal utility and the cut frontier?
9. Is its historical/canonical status consistent with the current master?
10. Do tests encode superseded behavior?
