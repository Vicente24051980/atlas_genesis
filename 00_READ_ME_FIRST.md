## En 2 minutos: Qué es esto

### No es un repositorio de GitHub cualquiera.
Es un **sistema operativo auditado** que:

✅ **Obliga a rigor** → Cada decisión pasa por 8 fases invariantes (ACK kernel)  
✅ **Cita siempre** → Toda conclusión tiene fuente primaria (SEC, earnings, etc.)  
✅ **Cuantifica incertidumbre** → CRC scoring (criticidad, confiabilidad, completitud)  
✅ **Busca refutación** → Mínimo 3 hipótesis alternativas + falsificadores  
✅ **Auditable** → Cada análisis es trazable, no hay black box  
✅ **Aprende** → Errores → protocolo mejorado  
✅ **Escalable** → Funciona para análisis pequeño o enorme  

### La Constitución lo gobierna
No puedes saltarte cosas. Ω-PEAJE-001 (8 niveles) es ley suprema.
